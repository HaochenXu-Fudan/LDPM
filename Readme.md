Python code for paper **Duality-Based Penalty Methods for Hyperparameter Optimization with Nonsmooth Structured Regularization**

## Abstract 

Hyperparameter optimization in regularized statistical learning naturally leads to bilevel problems with nonsmooth lower-level objectives. Existing methods often smooth the regularizers or solve sequential optimization subproblems, which can be costly for structured penalties. We develop a lower-level duality-based penalty framework that uses Fenchel duality and epigraph variables to replace the implicit lower-level solution constraint by a projection-friendly primal--dual merit penalty. This formulation yields two single-loop first-order methods: LDPM-PG for separable projection structures and LDPM-CS for nonseparable or overlapping structures handled by consensus splitting. Each iteration uses gradient evaluations, a proximal step for the conjugate loss, and standard epigraphical or conic projections, while preserving the original nonsmooth regularizers. We establish global consistency of exact minimizers of the increasing-penalty problems and fixed-penalty stationarity guarantees for the proposed algorithms, together with a KKT interpretation at the attained merit level. Numerical experiments on synthetic and real-world learning tasks illustrate competitive prediction or reconstruction quality and favorable runtimes relative to existing bilevel hyperparameter optimization methods, together with scalability across the tested dimensions.
